# Skyloop

Skyloop is a small 2D arcade game made with Lua and LÖVE. Pilot your jet, dodge asteroids, and try to get the highest score

## How to Play

- **Arrow keys** or **WASD**: Move the jet
- **Dodge asteroids**: Each asteroid you avoid adds 1 point
- **Space**: Restart after Game Over

## Run the Game

Install LÖVE, then open the game folder with the LÖVE application.

From a terminal, run:

```bash
love Skyloop
```
